# Notification Database Schema

Notification Service owns `notification_db`.

No other service may read or write this database directly.

## Tables

### notifications

Stores notifications created from consumed domain events.

| Column | Type | Constraints | Description |
| --- | --- | --- | --- |
| `id` | UUID | Primary key | Notification identifier |
| `recipient_role` | VARCHAR(80) | Not null | Role allowed to receive the notification |
| `recipient_user_id` | UUID | Nullable | Optional target user identifier |
| `type` | VARCHAR(80) | Not null | Notification type |
| `title` | VARCHAR(180) | Not null | Short notification title |
| `body` | VARCHAR(1000) | Not null | Notification message body |
| `read` | BOOLEAN | Not null | Whether the notification has been read |
| `created_at` | TIMESTAMP WITH TIME ZONE | Not null | Notification creation timestamp |
| `read_at` | TIMESTAMP WITH TIME ZONE | Nullable | Time the notification was marked read |
| `version` | BIGINT | Not null | Optimistic locking version |

## Constraints

- `id` is generated by Notification Service.
- New records must set `read` to `false`.
- `read_at` is null while `read` is false.
- Marking a notification read sets `read_at` when it is not already set.

## Indexes

```sql
CREATE INDEX idx_notifications_recipient_role ON notifications(recipient_role);
CREATE INDEX idx_notifications_recipient_user ON notifications(recipient_user_id);
CREATE INDEX idx_notifications_read ON notifications(read);
```

## Initial Migration

```sql
CREATE TABLE notifications (
    id UUID PRIMARY KEY,
    recipient_role VARCHAR(80) NOT NULL,
    recipient_user_id UUID,
    type VARCHAR(80) NOT NULL,
    title VARCHAR(180) NOT NULL,
    body VARCHAR(1000) NOT NULL,
    read BOOLEAN NOT NULL,
    created_at TIMESTAMP WITH TIME ZONE NOT NULL,
    read_at TIMESTAMP WITH TIME ZONE,
    version BIGINT NOT NULL
);

CREATE INDEX idx_notifications_recipient_role ON notifications(recipient_role);
CREATE INDEX idx_notifications_recipient_user ON notifications(recipient_user_id);
CREATE INDEX idx_notifications_read ON notifications(read);
```
